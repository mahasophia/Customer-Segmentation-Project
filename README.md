# Customer Segmentation Project

## Objective
Segment customers based on income and spending behavior using Machine Learning.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Features
- Data Visualization
- K-Means Clustering
- Elbow Method
- Customer Analysis
- Pie Chart Visualization

## Output
Customers are grouped into different clusters based on purchasing behavior.
